## What changed (Android only, path-filtered)

### P3-03d (PR #199) — auto-login restoration

- New `AuthSession(tokens: AuthTokens, user: AuthUser)` data class is the unit persisted by `TokenStorage`.
- `DataStoreTokenStorage` now persists user snapshot fields alongside tokens (`user_id`, `user_username`, `user_display_name`, `user_role`, `user_tenant_id` with `-1` sentinel for null tenant).
- `AuthRepository.restoreSession(): AuthUser?` — reads bundle once, returns user iff access token has ≥ 10 s TTL left.
- New `:app/navigation/SessionViewModel` (`@HiltViewModel`) + `SessionGate` composable. Gate runs once per process; resolves to spinner → either `VIPOSNavHost(startRoute = login)` or `VIPOSNavHost(startRoute = home/{name})`.
- `MainActivity` now mounts `SessionGate` instead of `VIPOSNavHost` directly.
- `:app` deps add `androidx-hilt-navigation-compose` + `lifecycle-runtime-compose` (the `collectAsStateWithLifecycle` artifact is separate from `lifecycle-viewmodel-compose` — gotcha tracked in `app/build.gradle.kts` comment).

### P3-03c (PR #200) — 2FA challenge UI

- `AuthApi.verify2fa(@Body Verify2FARequestDto): LoginResponseDto` wires the existing backend `POST /api/v1/auth/login/2fa` endpoint (`apps/backend/src/routes/auth.js:124-149`).
- `AuthRepository.verify2fa(loginToken, code, rememberMe): LoginResult` — mirrors `login()` shape; persists `AuthSession` on success; HTTP 401 surfaces "Kode 2FA salah atau sesi sudah berakhir".
- New `:feature:auth/ui/twofactor/`:
  - `TwoFactorUiState` + sealed `TwoFactorStatus` (Idle / Submitting / Authenticated).
  - `TwoFactorViewModel` (`@HiltViewModel`) — reads `loginToken` from `SavedStateHandle`. `onCodeChange` filters digits + caps at 6.
  - `TwoFactorScreen` + `TwoFactorRoute` — Material 3 form with OTP `OutlinedTextField` (`KeyboardType.NumberPassword` + `ImeAction.Done`), remember-me checkbox, error banner, _Verifikasi_ button (inline spinner during submit), _Batal_ button.
- New `VIPOSDestination.TwoFactor` route `"twofactor/{loginToken}"`. Both `TwoFactor.routeFor()` + `Home.routeFor()` URL-encode args via `Uri.encode()`.
- `VIPOSNavHost` adds `composable()` entry for `TwoFactor`. Login → TwoFactor keeps login on back-stack so _Batal_ pops back with username prefilled. TwoFactor → Home pops both auth surfaces inclusive (back-press from home exits the app).

## Critical infrastructure context

(Unchanged from `2026-05-06-p3-08-nav-graph.md` — the VM-level workarounds still apply to every future Devin session.)

- **`api` scope discipline** for `:core:*` and `:feature:*` modules when public API returns types (e.g., `OkHttpClient`, `Retrofit`, `RoomDatabase`, `LoginViewModel`, now also `AuthRepository` returning `AuthUser` from `restoreSession()` and `AuthSession` from `TokenStorage.read()`). Without `api` scope, downstream modules fail Hilt KSP with `error.NonExistentClass`.
- **Prettier vs. Room schema JSON**: `apps/android/core/database/schemas/` is in `.prettierignore`. Auto-generated by KSP; identity-hash check breaks if hand-edited.
- **`@HiltViewModel` requires KSP in the same module.** `:app` adds the KSP plugin + Hilt compiler whenever it gains a new ViewModel (e.g., `SessionViewModel` in PR #199).
- **`collectAsStateWithLifecycle` ships from `lifecycle-runtime-compose`**, NOT `lifecycle-viewmodel-compose`. Add the right artifact when a new module wires a Compose-Lifecycle bridge.
- **KDoc `*/` inside backticks closes the comment prematurely.** Paraphrase code references in KDoc instead of using inline-code spans for paths with `/`.
- **Git proxy 403 on push**: use the PAT-fallback recipe in `.agents/devin-vipos-continuous-automation.md` §4 (`GIT_CONFIG_NOSYSTEM=1` + `HOME=/tmp/empty-home` + `GIT_ASKPASS` script with `GITHUB_PAT_VIPOS`). The proxy works most of the time but PAT-fallback is the reliable escape hatch.
- **PR creation via REST API + `GITHUB_PAT_VIPOS`** is the standard path (not `git_pr` tool — historical proxy issues). After REST creates the PR, call `git_pr take_over` so future PR-management tool calls work.
- **Squash-merge via REST API** at `PUT /repos/.../pulls/<n>/merge` with `{"merge_method":"squash"}` is the only auto-merge path used here. Never force-push to main; always PR + squash.
- **VPS SSH may not be reachable from every Devin VM IP.** Two consecutive `ssh -o ConnectTimeout=15 root@103.74.5.44` attempts timed out at the banner exchange while HTTP traffic to the same host worked fine. This is intermittent across Devin sessions; if you hit it, fall back to HTTPS health checks or accept the VPS-verify gap as long as your PRs are path-filtered to `apps/android/**`.
