## Mobile considerations

- Settings rarely change; mostly read-only on mobile.
- One-time setup wizard during onboarding (or on first login).
- Owner / Manager access only; cashier mostly read-only.
- Some settings are device-local (e.g. printer pairing) — not synced.
- Critical: outlet selection persists; receipt template; tax rate; payment method config.
