VIPOS Deployment Instructions
==============================

Kode monitoring sudah di-push ke GitHub (commit c9795ca).
Silakan deploy ke production dengan cara:

OPSI 1 - SSH Manual:
--------------------
1. Buka terminal/PuTTY
2. ssh root@103.74.5.44
3. Jalankan commands berikut:

cd /var/www/vipos
git pull origin main
cd apps/backend
npm install --production
pm2 restart vipos-backend vipos-worker
sleep 3
curl http://localhost:3001/api/health

OPSI 2 - One-liner (jika SSH sudah configured):
------------------------------------------------
ssh root@103.74.5.44 "cd /var/www/vipos && git pull origin main && cd apps/backend && npm install --production && pm2 restart vipos-backend vipos-worker && sleep 3 && curl http://localhost:3001/api/health"

Setelah deploy, test endpoints baru:
-------------------------------------
1. Public metrics: http://103.74.5.44/vipos/api/metrics
2. Admin monitoring: http://103.74.5.44/vipos/api/admin/monitoring (perlu auth token)

Untuk get auth token:
---------------------
curl -X POST http://103.74.5.44/vipos/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
